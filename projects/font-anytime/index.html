Font Anytime

拍下手寫 A–Z，將辨識後的字母做成可安裝的字型。

專案簡介

用筆在紙上寫字母後拍照，瀏覽器會切割並辨識每個字。使用者可確認低信心結果或挑選重複字，預覽自己的手寫風格，補齊 A–Z 後下載 OpenType 字型。

使用技術

Canvas
處理圖像、二值化和連通區域切割。
int8 CNN
以瀏覽器內的 JavaScript 推論辨識 EMNIST 字母。
opentype.js
由向量字形組裝 CFF OpenType。
IndexedDB
保存字型資料夾及確認後的字母。

架構概覽

照片先切出候選字形，再用量化模型分類。人工確認後存入字庫，完整字庫可轉為可安裝字型。

  1. 拍照或選圖
  2. 切割並辨識字母
  3. 確認字形
  4. 向量化並下載 OTF

詳細架構

  • 影像切割

    自適應二值化後用 8 連通元件找出筆畫，合併同字母的片段並依閱讀順序排列。

    • js/segment.js↗

  • 辨識與校稿

    模型在本機對候選圖給出機率，前端讓使用者確認不確定的字母或挑選重複字。EMNIST 訓練與模型權重可分開檢視。

    • js/recognizer.js↗
    • js/app.js↗
    • tools/train-letters/train.py↗

  • 字形向量化

    沿像素輪廓描邊並簡化頂點，再以二次曲線平滑。OpenType 輸出將大小寫對應到已收集的手寫大寫字形。

    • js/font.js↗
    • js/storage.js↗

未來擴充構想

  • 字高與基線校正

    提供參考線與逐字覆寫，讓手寫字的上下位置和留白更一致。

  • 多樣本字形

    每個字母保留多種寫法，匯出成可切換的 OpenType 替代字形。

  • 標點與數字練習紙

    提供新的採樣模板與校稿格，把 0–9 和常用標點加入字庫。
