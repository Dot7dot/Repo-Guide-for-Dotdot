專案簡介

在瀏覽器裡散步、撿垃圾或換裝，沿著霧林步道尋找日夜出沒的生物。相機會根據取景、距離與遮擋給予評價，拍到的物種留在遊戲圖鑑。

使用技術

WebGPU / WGSL
手寫渲染管線，處理霧氣、光照、植被和色調映射。
JavaScript
即時生成地形、植被、動物模型及互動。
IndexedDB
存圖鑑照片，步行和解鎖進度另存在 localStorage。
Python
將自然手記的物種事實資料轉為遊戲使用的內嵌資料。

架構概覽

原始碼和著色器集中在同一份 HTML。建置會將它縮成自包含的發布檔，遊戲啟動後由瀏覽器生成場景和模擬生物。

  1. 載入場景程式
  2. 生成地形與物種
  3. WebGPU 繪圖
  4. 拍照更新圖鑑

  • 場景與效能

    地形、步道和植被由程式生成。渲染使用區塊視錐剔除、植被 LOD 與依幀時間調整解析度，並支援 WebGPU 相容路徑。

  • 生態與圖鑑

    生物出現機率參考月份、日夜與觀察統計。拍照時檢查取景範圍、大小與遮擋，將最佳照片和評價保存到圖鑑。

未來擴充構想

  • 攝影任務

    以晨霧、暮色或稀有動物為題，讓玩家用不同路線完成一組照片。

  • 觀察日誌

    在遊戲內並排顯示模擬目擊紀錄與來源物種的月份統計。

    顯示幀時間、解析度、可見區塊和植被級別，方便調整行動裝置的畫質。
