專案簡介

故事關卡從函式、迴圈教到動態規劃與堆積，另有每日和難度挑戰。提交程式後會執行測資，再量測成長趨勢，將表現轉成角色的獎勵和成就。

使用技術

Web Workers
將判題與量測放在工作執行緒，逾時可中止。
Pyodide
以 WebAssembly 在瀏覽器執行 Python。
Acorn / Python ast
分析及插樁提交的程式，量測運算與容器用量。
CodeMirror
提供瀏覽器內的程式編輯器。

架構概覽

題庫定義函式簽名、測資、參考解答與量測條件。前端選擇對應的 Worker 執行，通過後用逐步放大的輸入估計時間和空間成長。

  1. 選題並編輯
  2. Worker 執行測資
  3. 擬合成長曲線
  4. 評價與獎勵

詳細架構

    題目資料提供雙語參考解答、範例、測資產生器及比較規則。故事定義路線和課程，共用模型處理鏈結串列與樹。

未來擴充構想

  • 同題雙解比較

    保留兩次通過的提交，疊畫輸入大小與操作次數曲線。

  • 可攜題組

    讓老師匯入受版本控制的題目清單與測資，建立特定主題的城堡樓層。

  • 複習支線

    依先前失敗的觀念挑出短練習，幾天後重訪同一類問題。
