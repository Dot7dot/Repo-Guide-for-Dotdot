專案簡介

個人收藏庫依寶可夢的世代、編號和地區型態歸類。拍下實體卡可做透視校正，公仔或色違照片則能製成可翻面、會隨手勢反光的自製卡片。

使用技術

PokéAPI
提供圖鑑資料的來源與可載入的圖像。
Canvas
壓縮照片，並用四點對應校正實體卡的透視。
CSS 3D / DeviceOrientation
處理翻面、卡片傾斜和反光動畫。
IndexedDB
本機保存收藏文字與照片，支援 ZIP 備份。

架構概覽

靜態圖鑑與使用者收藏分開管理。前端以編號和型態關聯兩者；實體卡和自製卡各有處理流程，最後使用同一套卡片檢視。

  1. 選圖鑑與型態
  2. 拍攝並校正
  3. 保存收藏與照片
  4. 瀏覽立體卡

詳細架構

  • 圖鑑與索引

    基礎圖鑑包含多語名稱、世代與屬性，地區型態另有定義。收藏依編號與型態篩選，也能用文字和類別交叉搜尋。

  • 影像與卡片

    實體卡使用四角對應做透視校正。自製卡有獨立編輯介面，兩種卡的檢視都支援拖曳、翻面和可選的裝置方向。

    • js/capture.js↗

    • js/madecard.js↗

    收藏文字與照片位元組分開存放。備份檔含 collection.json 和可獨立讀取的照片，匯入可在其他裝置還原。

未來擴充構想

    挑選幾件收藏排成桌布或列印頁，讓相片和心得有多種排列。

    預覽新增、重複和有衝突的項目，再決定如何合併。
