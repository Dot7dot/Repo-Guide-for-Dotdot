Quantize Classroom

跟著互動 Notebook 親手把語言模型量化成 4-bit GGUF。

專案簡介

透過劇情、闖關和程式練習理解 4-bit 量化。學生在 CPU 上將 SmolLM2 轉成 F16 GGUF，再自己實作 Q4_0、比對 llama.cpp 的結果，最後執行模型並量測品質。

使用技術

Python / Jupyter
承載教學任務、檢查器與以 CPU 執行的實作。
GGUF / llama.cpp
處理模型轉檔、參考量化及推論。
PyTorch
支援必要的模型操作，並作為推論備案。
HTML / JavaScript
在 Notebook 內嵌入解剖台、分塊小遊戲等互動。

架構概覽

教材依任務呼叫檢查器與遊戲進度層。模型工具維護下載、GGUF 讀寫與官方工具執行，讓量化實驗和教學介面各自演進。

  1. 下載模型
  2. 轉成 F16 GGUF
  3. 實作 Q4_0
  4. 逐位元組比對與推論

詳細架構

  • 教材與進度

    Notebook 串接題目、提示和嵌入式介面。任務通過後發放 XP、徽章，進度保存到 quest_save.json。

    • quantize_classroom.ipynb↗
    • quest/checks.py↗
    • quest/game.py↗

  • 量化與模型格式

    參考實作負責分塊縮放與 4-bit 打包，GGUF 工具處理張量與中繼資料。教材將手工結果與 llama-quantize 的 Q4_0 張量逐位元組比較。

    • quest/q4.py↗
    • quest/ggufkit.py↗

  • 工具與完整測試

    工具箱處理模型和 llama.cpp 下載，並提供本機備用路徑。整本 Notebook 的測試會填入參考解答後逐格執行。

    • quest/toolbox.py↗
    • tests/run_notebook.py↗

未來擴充構想

  • 量化比較關卡

    以同一個小模型對照 Q4_0 與 Q8_0 的體積、輸出品質及推論耗時。

  • 誤差視覺化

    把量化前後的張量差異畫成熱圖，可切換區塊或標記離群權重。

  • 教師離線包

    產出可核對雜湊的課程快取與班級用測試報表，方便網路受限的教室。
