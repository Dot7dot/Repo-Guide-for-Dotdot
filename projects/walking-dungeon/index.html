Walking Dungeon

把真實步行距離換成地牢步數，探索並招募生物。

專案簡介

走路取得可在地牢使用的步數。每次離開後會生成新地牢，可找寶箱、採水果或餵食生物，讓牠們跟著探索。也能回小窩佈置家具或調整隊伍。

使用技術

Geolocation / DeviceMotion
從定位或動作感測取得步行進度。
Web Bluetooth
在支援的瀏覽器讀取 FTMS 和 RSC 裝置距離。
JavaScript
實作地牢生成、步數消耗、物品及生物互動。
PWA
快取遊戲外殼，進度保存於 localStorage。

架構概覽

走路追蹤器將不同感測來源換算成可消耗步數。遊戲規則與 DOM 分離，地牢、隊伍與小窩從相同狀態更新。

  1. 定位或其他計步
  2. 換算與對帳
  3. 消耗步數探索
  4. 存入遊戲進度
