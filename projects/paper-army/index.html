Paper Army

把手繪線條變成遊戲地形，觀察單位如何通過關卡。

專案簡介

在紙上畫線拍照，或用手指直接畫出關卡。調整裁切與偵測閾值後，從輪廓辨識出坡面、平台和機關，讓單位在手繪地形上自動對戰。支援單人關卡、同機與連線雙人遊玩。

使用技術

Canvas
擷取與處理圖像，繪製紙張、地形和動畫。
JavaScript
以固定時間步長推進遊戲模擬。
PeerJS / WebRTC
媒合雙人房間並傳輸地形和模擬快照。

架構概覽

影像處理先把草圖轉成網格與機關。模擬使用相同的地形和單位資料。在連線模式，由房主執行模擬並將快照傳給另一端。

  1. 佈陣與畫線
  2. 偵測線條與形狀
  3. 固定步長模擬
  4. 繪製與同步

詳細架構

  • 從草圖到地形

    沿用 Draft Collective 的局部亮度差偵測，將線條縮成網格。由外部填充判斷實心區，再以輪廓分析標記積水、圓滑面與其他機關。

  • 模擬與關卡

    模擬器更新移動、地形效果和結果。關卡資料定義敵方配置、可用地形和任務，教學文字由獨立模組提供。

    • js/sim.js↗
    • js/levels.js↗
    • js/solo-tutorial.js↗

  • 雙人同步

    兩人透過相同房間碼配對，各自提交地形與配置。房主合併地形並跑模擬，客端接收快照供繪圖。
