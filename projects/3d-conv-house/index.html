專案簡介

選擇要製作的物件，依各工具的說明上傳照片、調整參數，再預覽和下載 3D 檔。例如卡片走獨立轉換 API，角色與道具可直接在嵌入的 Char3D Converter 裡操作。

使用技術

Node.js / Express
提供物件清單與轉換 API 轉接。
JavaScript
依 manifest 動態繪製上傳欄位和參數。
model-viewer
在瀏覽器顯示可旋轉的 GLB 預覽。

架構概覽

API 型工具透過 manifest 宣告表單與輸出格式，嵌入型工具則各自帶完整介面。靜態部署與 Node 伺服器共用前端。

  1. 選擇物件
  2. 讀取清單與規格
  3. 呼叫或嵌入轉換器
  4. 預覽與下載

詳細架構

  • 轉換器登錄

    物件 ID、網址和類型集中在清單。API 型遵守 3d-conv/1 協定，嵌入型以 iframe 保留操作狀態，尚未設定的種類可呈現為未開放。

    • converters.json↗
    • README.md↗

  • 表單與預覽

    前端依 manifest 決定欄位、圖像尺寸限制和預設值，使用 FormData 上傳，將轉換回傳的模型交給預覽元件。

    • assets/app.js↗
    • index.html↗

  • 兩條請求路徑

    Node 模式由 Express 查詢 manifest 並轉送轉換請求。GitHub Pages 讀取靜態清單，API 型改由瀏覽器呼叫已開放 CORS 的轉換器。

    • src/app.js↗
    • test/hub.test.js↗

未來擴充構想

  • 跨工具規格測試

    提供 manifest 驗證器與固定範例素材，新增轉換器時可先確認協定相容性。

  • 模型體檢

    下載前提示面數、貼圖尺寸、座標方向與單位，方便對接不同遊戲引擎。

  • 同圖比較

    讓同一批素材套用不同參數並排預覽，記下最適合的轉換設定。
