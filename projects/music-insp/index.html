專案簡介

一首歌一個資料夾。可立即錄下旋律、記和弦或直接拖進音檔和文件。每個片段都能重新命名、試聽與下載，整首歌也可以連同文字和轉成 WAV 的錄音一起打包。

使用技術

MediaRecorder
使用瀏覽器麥克風即時錄製靈感片段。
Web Audio
解碼瀏覽器錄音，供 WAV 匯出使用。
IndexedDB
儲存歌曲資料夾、文字和檔案內容。
JSZip
按檔名打包片段及文字成歌曲 ZIP。

架構概覽

錄音、文字和上傳檔都以片段形式歸入歌曲。選擇匯出時再讀取內容，依需求轉碼後組成 ZIP。

  1. 建立歌曲
  2. 錄音、文字或上傳
  3. 保存片段
  4. 預覽或打包

詳細架構

  • 輸入公用模型

    錄音產生音訊 Blob，上傳保留檔案內容，文字即時保存。同個資料夾可混合不同類型的片段。

    • app.js↗
    • index.html↗

  • 本機資料與瀏覽

    IndexedDB 分開保存資料夾與片段，讀取時可轉成臨時網址供媒體預覽。舊資料夾的備註會轉成文字片段。

    • app.js↗
    • README.md↗

  • 音訊與打包

    匯出可透過 Web Audio 將錄音解碼後寫成 WAV。JSZip 將文字、錄音及上傳檔以可辨識的名稱打包。

    • app.js↗

未來擴充構想

  • 歌曲時間軸

    手動排列幾段錄音，邊播放邊標註主歌、副歌或待重錄片段。

  • 錄音波形書籤

    在波形上標出想保留的時間點，匯出以秒數標記的筆記。

  • 歌曲資料還原

    為 ZIP 加上片段型別與順序清單，讓備份可重新匯入並接著編輯。
