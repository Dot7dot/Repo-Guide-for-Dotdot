專案簡介

操控火柴人在去鼓伴奏中戰鬥，兩個攻擊鍵分別打出大鼓與小鼓，每次攻擊都會吸附到音樂的節拍格上。前拍與後拍的招式不同，敵人、尖刺和舞池也只在拍點行動。可選內建曲，或上傳自己的去鼓伴奏並設定 BPM。

使用技術

Canvas 2D
繪製火柴人、敵人、舞池背景和遊戲內 HUD。
Web Audio API
以音訊時鐘為主時鐘，排程鼓聲並程式合成音色。
JavaScript
以原生 ES Modules 實作，無相依與建置步驟。
Node.js
以內建測試執行器和 Playwright 稽核節奏精準度。

架構概覽

所有節拍事件都由音訊時鐘推算，不依賴計時器累加。純函式的節拍數學與 BeatSnap 可在 Node 測試，戰鬥、敵人和世界事件只訂閱節拍事件。

  1. 按下大鼓或小鼓
  2. 吸附到拍點格
  3. 判定與連段加成
  4. 世界隨拍點反應

詳細架構

  • 拍點吸附與判定

    純函式把按鍵時間換算成 tick，決定落在哪個落點格，並獨立計算準拍判定。連段、節奏型與狂熱量表也在核心層以可測試的方式實作。

    • js/core/beatSnap.js↗
    • js/core/beatMath.js↗
    • js/core/comboTracker.js↗
    • js/core/groove.js↗

  • 音訊時鐘與鼓組

    指揮器以音訊時間產生拍點事件，音訊引擎負責解碼、播放與排程。鼓組音色依拍位強弱合成，並加上齊奏、招架與連段音效。

    • js/audio/conductor.js↗
    • js/audio/audioEngine.js↗
    • js/audio/sfxVoices.js↗
    • js/core/bpmDetect.js↗

  • 戰鬥與歌曲驅動世界

    兩支鼓各有攻擊佇列，命中、齊奏與招架在戰鬥模組判定。敵人和尖刺只在拍點行動，歌曲能量段落決定生怪量與燈光強度。

    • js/game/combat.js↗
    • js/game/enemies.js↗
    • js/game/game.js↗
    • js/core/songMap.js↗

  • 選單與節奏稽核

    選單處理選歌、上傳、BPM 與延遲校正，設定存在本機。稽核工具以無頭瀏覽器檢查攻擊與事件是否落在拍點網格上。

    讓使用者依自己的歌曲標出段落與敵人密度，保存成可分享的小檔。

    指定要完成的節奏型，鼓勵玩家練習不同的鼓點組合。
