Water Town

每次記錄喝水，都能讓一座 3D 小鎮長出新景色。

專案簡介

設定水壺容量後記錄每日飲水，累積的水量讓小島擴張、植物生長和水源幣增加。小鎮土地達到 7×7 後會開放熱帶雨林，雨林再擴張後開放海底亞特蘭提斯，每個領地有自己的地形、植物與建築。可編輯布局、看飲水日記以及拍一張立體城市明信片。

使用技術

Three.js
即時渲染島嶼、植物、建築與畫面截圖。
JavaScript
將成長、解鎖與擺放規則獨立於介面。
PWA / localStorage
在裝置保存日記與小鎮，離線也可使用。
Node.js
以內建測試執行器驗證遊戲規則。

架構概覽

喝水事件先進到規則層，換算水量與遊戲狀態，再由介面及 Three.js 同步呈現。各領地的資料用視圖切換，共用水源幣與背包，遊戲狀態可用純 JavaScript 測試。

  1. 選水壺和飲量
  2. 計算水量及成長
  3. 解鎖領地並存檔
  4. 更新 3D 場景

    規則層處理有效水量、土地解鎖、植物棲地與每日成長，並以領地視圖讓同一套規則套用在小鎮、雨林與海底。領地的地形、植物和建築集中在獨立資料模組。

未來擴充構想

  • 小鎮成長縮時

    每日保存輕量布局快照，自動回放地形解鎖、新領地與新建物。

  • 島嶼生態導覽

    點選植物時標亮適合生長的格子，解釋和水邊、沙地或建物的關係。

  • 相片模式

    在不改變遊戲進度的情況下切換時間、天氣與裁切比例來拍攝小鎮。
