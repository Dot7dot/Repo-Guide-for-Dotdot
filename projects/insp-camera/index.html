專案簡介

專為快速收集視覺靈感設計。拍照後點取景框周圍的分類即可收存，也能從檔案匯入。相簿支援調整照片、加筆記、移動分類、分享或批次匯出。

使用技術

MediaDevices / Canvas
處理即時取景、選檔和照片裁切旋轉。
IndexedDB
在瀏覽器保存照片、分類、筆記與設定。
Web Share / ZIP
提供系統分享、單圖下載與按資料夾打包。
PWA
以 Service Worker 快取 App 自己的檔案。

架構概覽

相機與匯入是同一個影像管線的入口。轉成適合保存的照片後，使用者決定分類，收藏頁從本機資料讀取與編輯。

  1. 取景或匯入
  2. 壓縮照片
  3. 選資料夾保存
  4. 編輯或分享
