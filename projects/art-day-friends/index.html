專案簡介

用手機上傳手稿或直接在畫板畫圖，也可以記一段文字。好友能看當天的作品並留言。自己的畫累積在本機日曆，雲端分享只保留當日的壓縮副本，留言可隨日曆備份。

使用技術

JavaScript
管理日更動態、日曆、畫板與備份。
IndexedDB
保存較高畫質的畫作、本機日記和留言快取。
Supabase
在有設定時提供登入、好友、分享與留言。
Canvas
即時繪畫，並為同一張圖輸出本機、縮圖與雲端版本。

架構概覽

本機日曆與好友分享各有一份資料。相同前端可選本機示範後端或 Supabase 後端。

  1. 畫板或上傳
  2. 縮圖與壓縮
  3. 本機日曆
  4. 同步今日副本

詳細架構

  • 畫作處理

    畫板或照片得到同一套影像處理流程。本機版長邊上限 2048 px，雲端副本上限 1280 px，縮圖另行生成。

    • js/sketch.js↗
    • js/imaging.js↗
    • js/app.js↗

  • 後端介面

    啟動時依是否具備 Supabase 設定選擇實作。示範模式在目前的瀏覽器模擬帳號和動態，雲端模式走 Supabase Auth、資料表和 Storage。

    • js/backend-local.js↗
    • js/backend-supabase.js↗

  • 可見性與歸檔

    Postgres RLS 控制畫作與留言的可見性，過期的畫作副本由清理流程移除。本機歸檔獨立保存畫作、留言快取和匯出資料。

    • supabase/schema.sql↗
    • js/archive.js↗

未來擴充構想

  • 每週共畫題目

    好友可一起參加一個主題，各自上傳並保留原有的當日可見期限。

  • 日曆冊輸出

    選一段日期生成可列印的月曆或 PDF，保留畫作和經同意收錄的留言。

  • 離線發布佇列

    斷線時先保存本機，重連後讓使用者預覽並送出仍在當日的待分享作品。
