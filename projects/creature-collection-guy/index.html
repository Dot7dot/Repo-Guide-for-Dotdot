專案簡介

拍攝正方形照片，補上名稱和備註，整理成個人自然相簿。太平山圖鑑可依月份、類群或名稱探索，從物種頁也能帶入物種名稱開始記錄。照片先存入裝置，附近地名可稍後補上。

使用技術

Canvas
將相機或相簿圖像裁成正方形。
Geolocation
定位後交給 OpenStreetMap 或選用的 Google Places 查地點。
IndexedDB
在本機保存照片、備註、地點和待處理狀態。
Python
彙整物種資料和具授權的照片，產出靜態圖鑑。

架構概覽

相簿和地點查詢分開處理。記錄可以先保存，地名異步回填；物種圖鑑則在發布前整理成 JSON。

  1. 拍照與分類
  2. 寫入本機相簿
  3. 背景查詢地名
  4. 瀏覽或修訂

詳細架構

  • 相機與相簿

    相機與選檔共用裁切流程。保存時帶入日期、類別、名稱與備註，再以 IndexedDB 讀寫清單和詳細資料。

    • app.js↗

  • 附近地名

    預設依距離和地標類型挑出附近的 OpenStreetMap 地點，可設定 Google Places。暫時查不到時保留待查狀態並於重連後重試。

    • places.js↗
    • app.js↗

  • 圖鑑資料管線

    建置腳本整理園區、iNaturalist、TaiCOL 等來源。前端依學名、科名、特徵與月份觀察量搜尋或篩選。

未來擴充構想

  • 離線步道包

    先下載選定步道的物種條目與授權縮圖，讓沒有訊號時也能查閱。

  • 模糊定位分享

    輸出觀察卡時可選擇只顯示園區或步道，保留敏感物種位置在本機。

  • 季節觀察回顧

    依照片日期和地點做月度回顧，對照圖鑑的月份分布。
