專案簡介

將長期、每週或每日事項拆成勾選框、筆記與能量條。可拖曳排序、複製及封存資料夾，每日任務會按本地時間重置。完成任務可獲得卡包並建立自己的收藏。

使用技術

JavaScript
管理任務狀態、拖曳、滑動和開包視圖。
localStorage
儲存資料夾、每日任務及獎勵紀錄。
Fetch API
從卡牌服務載入並快取卡池。
SVG / Web Audio
即時繪製手寫介面、卡包動畫與音效。

架構概覽

任務、卡包與收藏使用單一版本化存檔。任務狀態變動先交給獎勵規則，卡牌資料則由獨立模組更新。

  1. 建立或排序任務
  2. 完成並驗證資格
  3. 發放卡包
  4. 開包加入收藏

詳細架構

  • 任務與手勢

    主畫面和資料夾視圖處理三種項目、封存及編輯。長按與滑動各有模組，將操作送回主程式。

    • js/sortable.js↗
    • js/swipe.js↗

  • 重置與獎勵去重

    每日清單跨過本地早上八點重置。同一天重做每日任務不重複獎勵，複製資料夾也會保留原任務的獎勵關聯。

    • js/store.js↗
    • js/main.js↗

  • 卡牌服務與開包

    卡池可在背景讀取，暫無符合系列的卡時保留未開卡包。開包動畫和卡片視覺沿用 CardKing 的做法。

未來擴充構想

  • 任務節奏日曆

    用熱力圖看不同資料夾的完成頻率，點日期可回顧實際完成項目。

  • 共享清單模板

    將資料夾匯出成沒有個人備註和獎勵狀態的模板，匯入後再開始。

    為多階段清單設計達標獎勵，讓完成一整組任務也有獨立成就。
