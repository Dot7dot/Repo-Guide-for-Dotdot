專案簡介

用不同書架管理閱讀筆記，在每本書中放入心得和多張照片。可跨書架搜尋書名、作者和心得，匯出含照片的 JSON 備份。

使用技術

IndexedDB
以獨立儲存區保存書架、書籍、照片和中繼資料。
Canvas
壓縮匯入照片，減少裝置上的儲存用量。
PWA
以 Service Worker 提供離線開啟及主畫面安裝。

架構概覽

書籍文字與照片位元組分開保存。文字可自動儲存，照片新增或刪除和書籍索引更新由同一筆交易完成。

  1. 選書架與書籍
  2. 記錄心得或選圖
  3. 寫入本機資料庫
  4. 搜尋或匯出

詳細架構

  • 本機資料模型

    資料庫將 shelves、books 和 photos 分開。照片的 ArrayBuffer 有獨立記錄，寫入時一起調整書籍的照片 ID 清單。

    • js/db.js↗

  • 照片壽命

    選檔時立即讀入內容再壓縮，避免依賴 iOS 的短期檔案。顯示時才建立 blob 網址，離開視圖後釋放。

    • js/image.js↗
    • js/app.js↗

  • 瀏覽與離線

    應用層處理書架路由、全域搜尋、內嵌照片檢視及備份。Service Worker 快取網站殼，離線時仍可開啟本機筆記。

    • js/app.js↗
    • sw.js↗

未來擴充構想

  • 段落卡片

    把選定照片和讀後心得組成帶書名、頁碼的可列印摘錄。

  • 閱讀回顧

    依標籤與時間隨機抽出舊心得，做成個人複習清單。

  • Markdown 匯出

    以書架和書籍建立資料夾，照片獨立輸出供其他筆記工具讀取。
