專案簡介

快速拍下紙上的草圖，回到畫冊裁切、擦拭、註記或套用素描等效果。線稿與風格處理會另存，使原始照片和可匯出的透明圖都能留存。

使用技術

Canvas
處理裁切、橡皮擦、透明線稿和像素濾鏡。
JavaScript
管理拍照、手勢、編輯狀態與圖片分享。
IndexedDB
在本機保存手稿、線稿、變體與筆記。
PWA
離線開啟相簿，支援加入手機主畫面。

架構概覽

相機或相簿提供影像。本機畫冊保留原圖，編輯流程可建立衍生圖或調整匯出的背景與檔案格式。

  1. 拍攝手稿
  2. 裁切與編輯
  3. 擷取線稿
  4. 儲存或分享

詳細架構

  • 畫冊與操作

    主程式處理拍照、相簿、回上一頁和圖片手勢，編輯時由畫布呈現裁切與擦拭結果。

    • app.js↗
    • index.html↗

  • 線稿與濾鏡

    局部平均亮度用來估算每個像素的線條強度。線稿可輸出透明 PNG，也可用作蠟筆、浮雕或素描效果的輸入。

    • filters.js↗

  • 裝置存檔

    IndexedDB 保存照片、版本與靈感筆記。Service Worker 支援離線載入外殼，輸出可選擇格式及單色背景。

    • db.js↗
    • sw.js↗
    • app.js↗

未來擴充構想

  • 漫畫分鏡輸出

    把數張手稿拖成一頁，保留每格旁的靈感筆記。

  • 非破壞式編輯紀錄

    把裁切、筆刷和濾鏡保存成可回放的步驟，便於在原稿上改參數。

  • 批次掃描

    用同一套線稿參數處理整疊紙稿的照片，另存為依頁序命名的 ZIP。
