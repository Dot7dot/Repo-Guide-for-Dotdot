Dot Health

把護眼、活動與休息打卡變成一座養動物的小農場。

專案簡介

完成日常健康小行為，讓目前飼養的動物獲得經驗值。動物達到 Lv5 後會搬進農場，下一隻接著孵化。紀錄頁能回看各類行為、每日得分與連續打卡的變化。

使用技術

JavaScript
以 ES Modules 分離活動資料、養成規則與各分頁。
localStorage
儲存行為、動物與設定，提供 JSON 和 CSV 匯出。
PWA
用 Service Worker 快取網站，支援離線開啟與加入主畫面。
SVG
以程式繪出動物外觀及統計圖。

架構概覽

打卡和引導計時都會送進同一套計分流程。畫面由本機狀態重新計算農場、連續天數與圖表。

  1. 活動或計時
  2. 紀錄與計分
  3. 動物成長
  4. 農場與統計

詳細架構

  • 活動定義與計時

    活動用固定 ID 關聯分類、步驟、時長、每日計分上限與文獻。計時器依步驟推進，完成後由共用動作層提交打卡。

    • js/data/activities.js↗
    • js/timer.js↗
    • js/actions.js↗

  • 養成規則

    遊戲層以當地日期計算上限與每日加成，更新目前動物的 XP。畢業後保留動物並孵出下一隻。

    • js/game.js↗
    • js/animals.js↗

  • 狀態與視覺化

    版本化存檔保存 logs、animals、設定和目前動物 ID。紀錄頁從行為資料彙整每日分數和活動熱力圖。

    • js/store.js↗
    • js/stats.js↗
    • docs/ARCHITECTURE.md↗

未來擴充構想

  • 自訂休息組合

    將數個既有活動排成可重複啟動的短流程，例如工作間隔的護眼加伸展。

  • 農場季節相簿

    把畢業日期、動物外觀和當月打卡總結做成可下載的小卡。

  • 活動來源更新紀錄

    在每個活動顯示文獻更新時間與版本差異，方便回查計分與內容調整。
