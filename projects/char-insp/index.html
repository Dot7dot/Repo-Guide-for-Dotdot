Char Insp

專案簡介

每個角色有固定欄位，包括中英文名、描述、對話、圖示、頭像和角色圖。透過拖放或拍照收集素材，修改自動保存，最後可分開匯出結構化文字與圖片。

使用技術

JavaScript
負責角色編輯、拖放、多圖排序與匯出。
IndexedDB
獨立保存角色文字和圖片內容。
JSON / CSV / ZIP
提供適合遊戲資料管線的輸出，以及完整備份。

架構概覽

編輯頁針對固定的角色欄位操作本機資料。供遊戲使用的文字與圖片輸出，以及可還原的完整備份走不同流程。

  1. 建立角色
  2. 填欄位與圖像
  3. 本機自動儲存
  4. 匯出或完整備份

詳細架構

  • 角色編輯

    各類圖片可以多選、排序或放大瀏覽，對話用可增刪的列表。文字自動儲存時可獨立更新角色紀錄。

    • js/app.js↗
    • js/db.js↗

  • 遊戲資料輸出

    文字可轉成 JSON 或適合試算表的 CSV，圖片依角色及用途分目錄壓縮。可選擇單一角色或全部。

    • js/export.js↗
    • js/zip.js↗

  • 完整備份與還原

    備份記錄原始 ID、文字、圖片與順序。匯入可合併或全量還原，先寫入備份內容，再於全量模式移除多餘舊資料。

    • js/backup.js↗
    • js/db.js↗

未來擴充構想

  • 角色模板版本

    保留固定欄位作預設，針對不同遊戲增加可選欄位並用版本遷移。

  • 對話預覽

    用名字和頭像把多角色的對話排成簡單視覺小說畫面。

  • 資產對接

    讓匯出的角色 ID 對應 Char3D 的模型檔，建立給遊戲載入的角色清單。
