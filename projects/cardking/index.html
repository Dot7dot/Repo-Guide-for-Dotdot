專案簡介

在手機瀏覽器收集卡牌。卡包依系列分組，開包有撕包、逐張翻牌和稀有提示。店內可查機率表，重複卡會換成金幣，也能在圖鑑看自己解鎖了哪些卡。

使用技術

JavaScript
實作分系列抽卡、稀有度權重與機率表。
Fetch / localStorage
讀取遠端卡池並快取，收藏與金幣保存在裝置。
SVG / Web Audio
繪製手繪卡框、開包效果並合成音效。

架構概覽

卡池來自外部服務，遊戲直接在瀏覽器算抽卡與收藏規則。資料和機率規則集中，呈現層負責動畫與卡片檢視。

  1. 載入及快取卡池
  2. 依權重抽牌
  3. 開包動畫
  4. 更新收藏與圖鑑

詳細架構

  • 卡池與機率

    卡池按 set 分組。先依權重抽出稀有度，再從該稀有度抽卡，另決定卡面型態。機率表從同一套規則計算。

    • js/data.js↗

  • 遊戲經濟

    紀錄金幣、卡包與收藏。重複卡轉換金幣，圖鑑達成階段目標時會補發該系列卡包。

    • js/data.js↗
    • js/main.js↗

  • 開包表現

    開包流程管理動畫、翻牌順序和略過操作，蠟筆線條、粒子和音效由不同模組即時產生。

    • js/crayon.js↗
    • js/sfx.js↗

未來擴充構想

  • 機率模擬器

    比較理論分布和可重現的大量抽樣，調整權重時也能檢查機率表。

  • 系列收藏冊

    按主題或卡面型態自由排版，挑出代表卡製作可分享的圖卡。

  • 自訂離線卡池

    匯入一組合法授權的本地卡圖和卡池 JSON，讓個人系列也能在離線時測試。
