專案簡介

先輸入手掌長度，或拍下手掌和硬幣完成校正。搜尋食物後在畫布圈出份量，依形狀調整厚度或直接輸入重量，再將估算的營養加入當日紀錄。

使用技術

MediaPipe
用 Hand Landmarker 找手腕與中指指尖。
Canvas
讓使用者在已校正的畫布上圈出食物輪廓。
JavaScript
載入食物目錄、套用幾何估算並彙整每日紀錄。
PWA
支援安裝與離線使用，設定及紀錄留在 localStorage。

架構概覽

校正模組提供手掌長度。前端把畫布尺度映射到公分，以食物的密度、可食比例與每百克營養資料計算估值。

  1. 校正比例
  2. 選食物並圈形
  3. 換算重量
  4. 計算並記錄營養

詳細架構

  • 拍照校正

    手部模型在本機找出掌長端點，影像處理估計硬幣位置與尺寸。使用者可以微調標記或手動輸入量測值。

    • js/measure.js↗

  • 份量換算

    依食物資料選用近似橢球、片狀或堆狀的體積計算，再乘密度及可食比例。紀錄頁加總同一天選入的食物。

    • js/app.js↗
    • foods/_template.json↗

  • 營養資料目錄

    單筆食物 JSON 是編輯來源，建置工具檢查資料並輸出分批載入目錄。前端遇到不一致的目錄會改為有限並行載入單檔。

    • foods/README.md↗
    • tools/build-catalog.mjs↗
    • js/app.js↗

未來擴充構想

  • 份量範圍

    讓使用者調整輪廓與厚度的誤差，顯示估算重量與營養的可能區間。

  • 常吃組合

    保存一份由多種食物組成的早餐或便當，下次帶入後只調整份量。

  • 資料來源卡片

    在結果旁展開原始資料、生熟狀態和缺值，方便比較同類食材。
