專案簡介

這個網站收錄 2026 年 10 月起建立的公開 GitHub 專案。首頁提供依類別與技術關鍵字瀏覽的卡片，詳情頁把用途、資料流、原始碼入口和擴充構想放在一起，方便快速判斷要從哪裡開始讀。

使用技術

Node.js
在建置時讀取專案資料並輸出首頁和每個專案的 HTML。
HTML / CSS
提供可直接開啟的詳情網址與響應式色塊排版。
JavaScript
在瀏覽器過濾既有卡片，並把條件同步到網址。
GitHub Pages
從 main 分支發布建置好的靜態頁。

架構概覽

一份專案資料驅動首頁與詳情頁。瀏覽器直接讀取建置後的 HTML，只在搜尋與篩選時需要執行 JavaScript。

詳細架構

  • 專案資料

    每筆以固定 slug 產生獨立網址。建立日期、技術用途、資料流、原始碼路徑與構想集中維護。

    • data/projects.json↗

  • 靜態建置

    檢查 slug、類別與相關專案參照，依建立日期輸出卡片與詳情頁。資產以相對路徑載入，可部署在 repo 子路徑。

    • scripts/build.mjs↗

  • 瀏覽與發布

    關鍵字和類別可交叉篩選，網址記錄目前條件。GitHub Pages 從 main 根目錄直接發布網頁和樣式，透過 .nojekyll 跳過 Jekyll。

    • public/catalog.js↗
    • README.md↗

未來擴充構想

  • 新 repo 待整理清單

    定期比對公開 repo 清單，開出待補架構說明的 PR，讓發布前仍可人工校對。

  • 跨專案技術地圖

    將共用的 IndexedDB、PWA 與影像處理流程做成可點擊的關聯圖。

  • 來源變更提示

    對照記錄的 commit，提醒維護者重新核對已搬移或改寫的模組連結。
