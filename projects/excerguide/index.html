專案簡介

選擇健走、跑步、重訓等類別，記下名稱、時長和備註。首頁彙整今日與本週活動時間，也會依運動強度和體重估算熱量，適合用來回顧自己的運動節奏。

使用技術

HTML / CSS
製作黑黃色塊介面、類別入口和進度條。
JavaScript
管理輸入、估算和日期分組。
localStorage
在裝置上保存運動紀錄與目標設定。

架構概覽

單頁以原生表單和事件處理新增、編輯及刪除紀錄。每天與每週的統計都由紀錄時間重新計算。

  1. 選擇運動
  2. 輸入時間與備註
  3. 估算並保存
  4. 更新週進度

詳細架構

  • 介面與類別

    HTML 提供首頁、表單與設定。各類別的 MET 值和小知識放在 app.js 的資料定義，可在選取類別時帶入名稱。

    • index.html↗
    • app.js↗

  • 估算和統計

    用 MET、體重和運動時間估算熱量。以本地時間建立每日、每週起點，彙整分鐘數並比對每週目標。

    • app.js↗

  • 本機儲存

    紀錄和個人設定以 JSON 寫入 localStorage。共用讀寫函式讓沒有資料的首次使用可套用預設值。

    • app.js↗

未來擴充構想

  • 每週訓練對照

    以小圖比較有氧、肌力和伸展的時間比例，以及近四週進度。

  • 快速記一筆

    為常做的運動保留時間和名稱範本，完成後可以一鍵新增紀錄。

  • 資料匯出

    支援 CSV 匯出與檢查重複資料的匯入流程，方便做自訂分析。
